# البورتفوليو الإداري - الأستاذة عائشة علي القحطاني

موقع بورتفوليو إلكتروني تفاعلي للمساعد الإداري (ممارسة ثاني) بالابتدائية الثلاثون بأبها.

## طريقة الرفع على GitHub Pages:
1. قم بفك الضغط عن هذا الملف.
2. أنشئ Repository جديد على GitHub باسم `portfolio` أو أي اسم آخر.
3. ارفع الملفات الموجودة في هذا المجلد (`index.html` ومجلد `images`).
4. اذهب إلى **Settings** -> **Pages** واختر الفرع `main` ثم اضغط **Save**.
5. سيعمل موقعك مباشرة برابط مجاني!
